# CalReg — Calisthenics Registration

PWA / TWA de seguimiento **personal** de calistenia (solo peso corporal).

**Desarrollado por Oscar Antonio Alvarez Collado**

## Enfoque
- Uso personal (sin rankings ni leaderboards sociales)
- Capacidades actuales + gráfico radar (pentágono)
- Fecha de inicio de entrenamiento → conteo exacto de días
- Evaluación de rango por ejercicio (reps / técnica / variaciones)
- Biblioteca con nombres técnicos, dificultad 0-10 + rango, y **árbol de progresiones**
- Temas oscuro/claro + color de acento personalizable
- Iconos SVG propios (sin emojis)

## Cómo probar
```bash
cd calisbros
npx serve .
# o: python3 -m http.server 8080
```

Luego instala como PWA desde el navegador.
